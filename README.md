# 背单词 · 自然拼读学习卡片

面向小学生(三年级左右)的英语单词学习网页。1379 个单词、34 个分组,每个单词都带有 **AI 生成的 DJ 音标** 和 **自然拼读分段标注**,支持整词真人发音、逐音素拼读播放、同义词/反义词/缩略词双卡片展示。

纯静态页面,无需构建工具,直接打开即可使用。

## 功能一览

- **彩色拼读卡片**:单词按自然拼读分段着色 —— 单辅音(蓝)、辅音组合(紫)、单元音(红)、元音组合(橙)、长元音 magic-e(绿)、不发音字母(灰)。
- **🔊 播放发音**:有道真人词典发音,浏览器 TTS 兜底。
- **🔤 自然拼读**:逐音素播放 pindushu 真人录音,当前分段同步高亮,最后整词朗读;可随时打断,按钮不会卡死。
- **词对双卡片**:同义词组(32)、反义词组(33)、缩略词组(34)以左右两张小卡片展示,每张卡片有自己的音标行和发音/拼读按钮;**卡片打开时自动连续朗读两侧单词**(如 `hi → hello`、`there is → there's`);缩略词自动保留词间空格(如 `who is`),缩写连写自动合并(如 `isn't` 不分家)。
- **学习进度**:「✓ 已会」标记 + 「＋ 生词本」收集,均存 localStorage;侧边导航列出本组全部单词、点击跳转、当前词高亮。
- **随机顺序**:每次进入分组单词洗牌,完成时弹出总结页。
- 键盘快捷键:← / → 切换单词。

## 文件结构

```
背单词/
├── index.html            页面结构 + 全部样式
├── app.js                全部逻辑(渲染、发音、拼读序列、存储)
├── words.json            ★ 数据源:34 组词条,含 AI 生成的音标 w 字段
├── words.js              生成产物:拍平后的 WORDS_DATA(app.js 直接加载)
├── build_words_js.mjs    生成脚本:words.json → words.js
├── validate_words.mjs    校验脚本:结构 + 铁律 + 拼读映射覆盖检查
├── words.json.bak        合并 w 字段前的备份
└── audio/phonemes/       48 个 DJ 音素真人录音(mp3,来自 pindushu)
```

## 数据流

```
words.json  --(node build_words_js.mjs)-->  words.js  --(script 标签)-->  app.js 渲染
     ↑
  AI 生成/人工修订 w 字段后,先跑 node validate_words.mjs 校验
```

`words.js` 中每条词条有顺序编号 `id`(1~1379),它被 localStorage 的「已会/生词本」直接引用,**因此词条顺序绝不能变**。生成脚本内置了 id 漂移保护:重新生成时会与旧 `words.js` 逐条比对英文原文,顺序变了会报错拒写。

## 数据格式(words.json)

每个词条:

```json
{ "en": "apple", "zh": "苹果", "w": [ ["apple", "ˈæpəl", [["a","v","æ"],["pp","c","p"],["l","v","ə"],["e","l","l"],["t","s",""]]] ] }
```

- `en`:英文原文;`zh`:中文释义(缩略词组无释义则省略)。
- `w`:**按单词里的每个字母串(`en.match(/[A-Za-z]+/g)`)一一排列**,每项为三元组:
  1. 字母串原文(保留大小写与内部拼写),
  2. 该词段的 DJ 音标(英式;含 `ˈ` `ˌ` 重音符),
  3. 拼读分段数组:`[字母, 类型码, 该分段读音]`。
- 类型码:`c`=单辅音、`d`=辅音组合、`v`=单元音、`t`=元音组合、`l`=长元音(magic-e 结构)、`s`=不发音。
- 词对词条(syn/ant/abbr)在 `en` 中用 ` – `(两侧单词)或 ` = `(缩写展开)连接,`w` 覆盖两侧所有字母串。

### 铁律(校验脚本机械检查)

- **A**:每个词段的分段字母拼接 == 词段原文;
- **B**:分段读音拼接 == 音标去掉重音符(`ˈ` `ˌ`,保留 `ː`)。

违反铁律 = 卡片上色分段和拼读播放都会错位,所以改数据后必须跑校验。

## 如何扩充词库(未来加词指南)

1. **编辑 `words.json`**,把新词条**追加到对应分组的末尾**(分组数量、既有词条顺序都不动 —— id 稳定性保护)。
2. **为新词条生成 `w` 字段**。可以直接让 AI 按上面的格式生成(提示词里务必带上"铁律"和类型码约定,并给出 2~3 个现成词条作为示例)。生成量大时按批次交给脚本处理,不要逐词手改。
3. **校验**:`node validate_words.mjs`。它会检查结构、两条铁律、类型码,并报告哪些读音还没有拼读音频映射。
4. **补拼读映射**(仅当校验报缺时):在 `app.js` 的 `IPA_TO_PHONEMES` 中为新读音增加条目,值是一个或多个音素音频 id(对应 `audio/phonemes/ph_<id>.mp3`)。组合音可拆成多个音素顺序播放,如 `"ks": ["k","s"]`。44 个 DJ 音素的录音已齐全,通常只有罕见读音才需要动这里。
5. **重新生成**:`node build_words_js.mjs`(内置 id 漂移保护,顺序被改动会拒写并提示)。
6. **刷新页面抽查**:新词出现在分组末尾,颜色分段正确,两个按钮都能播完整序列。

若涉及新词对(同义/反义/缩写),按第 32~34 组的 `en` 写法(` – ` / ` = `)添加即可,双卡片 UI 自动生效。

## 发音音源

| 用途 | 来源 | 说明 |
|---|---|---|
| 整词发音 | `https://dict.youdao.com/dictvoice?audio=单词&type=2` | 真人词典录音;失败时浏览器 TTS 兜底 |
| 音素拼读 | 本地 `audio/phonemes/ph_*.mp3` | 44 个 DJ 音素,取自 pindushu;本地缺失时回退 `https://img.pindushu.com/phonics/audio/phonemes/` |
